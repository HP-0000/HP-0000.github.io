디버그(Debug) ➔ 창(Windows) ➔ 직접 실행(Immediate)
디버그(Debug) ➔ 창(Windows) ➔ 조사식(Watch)

디버거가 정확한 심볼을 찾을 수 있도록 다음과 같이 3가지의 힌트를 제공할 수 있다.
```text
{스코프,소스파일,모듈명} 심볼
```
디버그(Debug) ➔ 창(Windows) ➔ Modules 에서 현재 올라온 모듈명들을 확인할 수 있다.
 
다음과 같이 쓰면 모듈 전역에서 찾도록 명령할 수 있다.
```text
{,,모듈명}심볼
```

심볼만 적는 경우 현재 모듈에 한정하여 찾는다.

---

###### 포맷 지정자 (Format Specifiers)

변수 뒤에 콤마(`,`)와 알파벳을 붙여 메모리를 원하는 형태로 강제 변환해 출력한다.

| 문법 | 설명 | 출력 예시 |
| :--- | :--- | :--- |
| , ! | Natvis 해제 (원시 C++ 멤버 노출) | {Data=0x000... ArrayNum=5 ArrayMax=10} |
| , view(이름) | Natvis의 특정 커스텀 뷰(모드) 선택 | {CustomFormattedView} |
| , nd | 부모 클래스 멤버만 보기 (자식 멤버 가림) | {BaseVar=10} |
| , na | 객체 주소값 숨김 | {X=10.0 Y=20.0 Z=0.0} |
| , su | UTF-16 유니코드 문자열 (TCHAR*) | L"플레이어_1" |
| , s8 | UTF-8 문자열 | u8"Hello" |
| , s | ANSI 문자열 (char*) | "GameStarted" |
| , sb | 문자열 앞뒤 따옴표("") 제거 | 플레이어_1 |
| , [숫자] | 포인터를 해당 크기 배열로 확장 | [0]=10, [1]=20, [2]=30 ... |
| , x | 16진수 변환 | 0x000037c8 |
| , b | 2진수 변환 | 0b00000010 |
| , o | 8진수 변환 | 0177 |
| , d | 부호 있는 10진수 강제 | -1 |
| , u | 부호 없는 10진수 강제 | 4294967295 |
| , m | 메모리 기본 덤프 (16바이트) | 00 1A FF 4C ... |
| , mb | 1바이트(Byte) 단위 16진수 덤프 | 0A 1F FF ... |
| , mw | 2바이트(Word) 단위 16진수 덤프 | 1F0A FF4C ... |
| , md | 4바이트(Dword) 단위 16진수 덤프 | FF4C1F0A ... |
| , mq | 8바이트(Qword) 단위 16진수 덤프 | 00000000FF4C1F0A ... |
| , hr | HRESULT / DirectX 에러 코드 해석 | DXGI_ERROR_DEVICE_REMOVED |
| , wm | 윈도우 메시지 번호 해석 | WM_PAINT |
| , c | 단일 문자로 변환 | 'A' |
