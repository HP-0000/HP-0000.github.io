$$I = \int_{-\infty}^{\infty} e^{-x^2} \, dx$$

## 2. 해결의 핵심 아이디어: 2차원으로 차원 확장 ($I \to I^2$)

1차원(선)에서 풀리지 않으므로, **똑같은 적분값 $I$를 두 번 곱해 2차원(면) 부피 적분 문제로 확장**합니다.

* $I = \int_{-\infty}^{\infty} e^{-x^2} \, dx$
* $I = \int_{-\infty}^{\infty} e^{-y^2} \, dy$ *(변수 이름만 $y$로 바꾼 동일한 값)*

두 값을 곱하면:

$$I^2 = I \times I = \left( \int_{-\infty}^{\infty} e^{-x^2} \, dx \right) \left( \int_{-\infty}^{\infty} e^{-y^2} \, dy \right)$$

지수법칙($e^A \times e^B = e^{A+B}$)에 따라 하나로 합쳐집니다:

$$I^2 = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} e^{-(x^2 + y^2)} \, dx \, dy$$

## 3. 좌표계 변환: 직교좌표계 $(x, y) \rightarrow$ 극좌표계 $(r, \theta)$

$x^2 + y^2 = r^2$ (피타고라스 정리)임을 이용하여 **반지름 $r$과 각도 $\theta$의 극좌표계**로 변환합니다.

```
       [ 직교좌표계 (x, y) ]                  [ 극좌표계 (r, θ) ]
   y                                      y
   |   (모눈종이 격자 방식)                 |     / (r, θ)
   |--+----+                               |    /
   |  |    |                               |   / r
   +--+----+-- x                           +--/------> x
                                             θ
```

### ① 적분 범위의 변환 (2차원 전체 평면 훑기)
* **기존 ($x, y$):** $x: -\infty \sim \infty$, $y: -\infty \sim \infty$ $\rightarrow$ **2차원 평면 전체**
* **변환 ($r, \theta$):**
  * **반지름 $r$:** 원점($0$)부터 무한히 멀어져야 하므로 $\mathbf{0 \sim \infty}$
  * **각도 $\theta$:** 한 바퀴를 완벽히 돌려야 하므로 $\mathbf{0 \sim 2\pi}$

### ② 면적 요소의 변환 ($dx \, dy \rightarrow r \, dr \, d\theta$)
미세한 조각 하나(미소 면적)의 넓이를 계산할 때:

* **직교좌표계:** 가로 $dx \times$ 세로 $dy = \mathbf{dx \, dy}$ (직사각형)
* **극좌표계:** 반지름 두께 $dr \times$ 호의 길이($r \, d\theta$) = $\mathbf{r \, dr \, d\theta}$ (부채꼴 조각)

> **💡 왜 $r$이 곱해질까?**  
> 중심각 $d\theta$가 일정할 때, 원점에서 멀어질수록($r$이 커질수록) 부채꼴 호의 길이가 $r$배 길어져 조각의 넓이가 비례해서 커지기 때문입니다. (야코비안 행렬식 $J = r$)

---

## 4. 단계별 최종 계산 과정

### Step 1. 극좌표계 적용하기
변환된 요소들을 $I^2$ 식에 대입합니다.

$$I^2 = \int_{0}^{2\pi} \int_{0}^{\infty} e^{-r^2} \cdot \mathbf{r \, dr \, d\theta}$$

### Step 2. $r$에 대해 치환적분하기
이제 식 옆에 **속미분 짝꿍인 $r$**이 생겼으므로 치환적분이 가능합니다!

* $u = r^2$ 로 두면 $\implies du = 2r \, dr \implies r \, dr = \frac{du}{2}$
* 구간: $r = 0 \to u = 0$, $r = \infty \to u = \infty$

$$\int_{0}^{\infty} e^{-r^2} r \, dr = \int_{0}^{\infty} e^{-u} \frac{du}{2} = \frac{1}{2} \left[ -e^{-u} \right]_{0}^{\infty} = \frac{1}{2}(0 - (-1)) = \mathbf{\frac{1}{2}}$$

### Step 3. $\theta$에 대해 적분하고 결론 내기
$$I^2 = \int_{0}^{2\pi} \left( \frac{1}{2} \right) \, d\theta = \frac{1}{2} [\theta]_{0}^{2\pi} = \frac{1}{2} \times 2\pi = \mathbf{\pi}$$

$$I^2 = \pi$$

피적분함수 $e^{-x^2} > 0$ 이므로 적분값 $I$는 항상 양수입니다.

$$\therefore I = \int_{-\infty}^{\infty} e^{-x^2} \, dx = \mathbf{\sqrt{\pi}}$$
