[미분](/Public/Study/Math/Docs/미적분/미분)

$a$부터 $x$까지의 $f(x)$가 형성하는 넓이를 나타내는 함수를 
$g(x) = \int_a^x f(t) dt$ 라고 할 때, $g(x)$의 도함수를 구하면 원래 함수 $f(x)$가 된다

###### 증명

도함수의 정의는 다음과 같다.
$g'(x) = \lim_{h \to 0} \frac{g(x+h) - g(x)}{h}$

   $$g(x+h) - g(x) = \int_a^{x+h} f(t) dt - \int_a^x f(t) dt = \int_x^{x+h} f(t) dt$$

[평균값 정리](/Public/Study/Math/Docs/미적분/평균값%20정리)
   $$\int_x^{x+h} f(t) dt = f(c) \cdot h \quad (x \le c \le x+h)$$
   $$g'(x) = \lim_{h \to 0} \frac{f(c) \cdot h}{h} = \lim_{h \to 0} f(c)$$

   $h \to 0$ 라면  $c \to x$ 임으로 
   [샌드위치 정리](/Public/Study/Math/Docs/극한/샌드위치%20정리)
   
   $$g'(x) = f(x)$$

$F'(x) = f(x)$ 라고 하면, $g(x) = F(x) - F(a)$ 임으로 

$$F(X) = F(a) + \int_a^{x} f(t) dt$$
