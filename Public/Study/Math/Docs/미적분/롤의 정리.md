$g(x)$가 닫힌구간 $[a, b]$에서 연속이고 열린구간 $(a, b)$에서 미분가능하며
$g(a) = g(b)$일때 $g'(c) = 0$인 $c$가 구간 $(a, b)$에 적어도 하나 존재한다

# 증명

$M$ : $[a, b]$ 구간에서 함수 최대 값 
$N$ : $[a, b]$ 구간에서 함수 최소 값
- $M = N$ 인 경우 상수 함수가 되어 도함수 값은 0

$M$ 을 만드는 $x$ 좌표를 $c$ 로 두면 아래의 식이 성립한다
$f(c+h) \le f(c)$
$$\lim_{h \to 0^+} \frac{f(c+h) - f(c)}{h} \le 0$$ $$\lim_{h \to 0^-} \frac{f(c+h) - f(c)}{h} \ge 0$$미분이 가능하려면 좌 미분 계수와 우 미분 계수가 같아야 함으로
$$f'(c) = \mathbf{0}$$
