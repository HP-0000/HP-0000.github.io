> $$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x - a)^k + \mathbf{\frac{1}{n!} \int_a^x (x - t)^n f^{(n+1)}(t) \, dt}$$

# 증명
$$f(x) - f(a) = \int_a^x f'(t) \, dt$$
$$f(x) = f(a) + \int_a^x \mathbf{1 \cdot f'(t)} \, dt$$

$\int u v' \, dt = [uv] - \int u' v \, dt$ 
* $u = f'(t) \implies u' = f''(t)$
* $v' = 1$
* $v = -(x - t)$

$$\int_a^x 1 \cdot f'(t) \, dt = \Big[ -(x - t)f'(t) \Big]_a^x - \int_a^x \Big(-(x - t)\Big) f''(t) \, dt$$
$$f(x) = f(a) + \mathbf{f'(a)(x - a)} + \mathbf{\int_a^x (x - t) f''(t) \, dt}$$

 $\int_a^x (x - t) f''(t) \, dt$  부분 적분 
* $u = f''(t) \implies u' = f'''(t)$
* $v' = (x - t) \implies \mathbf{v = -\frac{(x - t)^2}{2}}$

$$\int_a^x (x - t) f''(t) \, dt = \left[ -\frac{(x - t)^2}{2} f''(t) \right]_a^x + \int_a^x \frac{(x - t)^2}{2} f'''(t) \, dt$$
$$f(x) = f(a) + \mathbf{f'(a)(x - a)} + \mathbf{\frac{f''(a)}{2}(x - a)^2} + \mathbf{\frac{1}{2}\int_a^x (x - t)^2 f'''(t) \, dt}$$
이를 일반화 하면 
* $u = f^n(t) \implies u' = f^{n+1}(t)$
* $v' = (x - t)^{n-1} \implies \mathbf{v = -\frac{(x - t)^{n}}{n}}$
 $$
 \int_a^x (x - t)^{n-1} f^n(t) \, dt =  
 \left[-\frac{(x - t)^{n}}{n} f^n(t) \right]_a^x + \int_a^x(x - t)^{n}
 \frac{f^{n+1}(t)}{n} \, dt
 $$  $$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x - a)^k + \mathbf{\frac{1}{n!} \int_a^x (x - t)^n f^{(n+1)}(t) \, dt}$$

급수에 존재하는 다항식을 [테일러 전개](/Public/Study/Math/Docs/근사/테일러%20전개) 로 볼때
오차 항은 다음과 같다.
$$R_n(x) = \mathbf{\frac{1}{n!} \int_a^x (x - t)^n f^{(n+1)}(t) \, dt}$$
$(x - t)^n$이 항상 부호가 일정함으로 적분의 [평균값 정리](/Public/Study/Math/Docs/미적분/평균값%20정리) 를 적용하면 라그랑주 잉여항을 얻는다.

$$R_n(x) =
\frac{f^{(n+1)}(( \xi \mid a,x ))}{n!} \int_a^x (x - t)^n \, dt
= \frac{f^{(n+1)}(( \xi \mid a,x ))}{(n+1)!}(x - a)^{n+1}$$
