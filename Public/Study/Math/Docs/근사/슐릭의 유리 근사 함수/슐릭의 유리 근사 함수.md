$$g(x) = \frac{x}{x(1-k)+k} = \frac{1}{1 + k \cdot \left(\frac{1-x}{x}\right)} \quad (x \in [0, 1], \; k > 0)$$

지수 연산을 대체하여 $0 \sim 1$ 구간의 곡률을 효율적으로 제어, 연산할 수 있다.

###### 파라미터 $k$에 따른 곡선 제어
* $k = 1$ (선형): $g(x) = x$ (대각선 직선)
* $k < 1$ (위로 볼록): $x$가 줄어들어도 $g(x)$가 한동안 $1$ 근처를 유지하다가, 
  $x \to 0$ 극소 구간에서 $0$ 으로 급격히 떨어짐
* $k > 1$ (아래로 볼록): $x$가 $1$에서 조금만 감소해도 $g(x)$가 빠르게 $0$을 향해 감쇄

###### 정규화된 입력 범위 유지
* $g(0) = 0$
* $g(1) = 1$

###### 단조 증가성
$$g'(x) = \frac{k}{\big(x(1-k) + k\big)^2}$$
모든 $x \in [0, 1]$ 구간에서 $g'(x) > 0$ 임으로 항상 부드럽게 증가

###### 역함수의 구조적 불변성
$$g^{-1}(y) = \frac{y}{y\left(1 - \frac{1}{k}\right) + \frac{1}{k}}$$
새로운 파라미터 $k' = \frac{1}{k}$로 두면 역함수가 된다.
$$g^{-1}(y) = \frac{y}{y(1 - k') + k'}$$

###### Gain Function
$k$와 상관 없이 아래를 만족함으로 
* $g(0) = 0$
* $g(1) = 1$

슐릭의 유리 근사 함수에 대하여
$$g_{left} = \frac{x}{x(1-k_l)+k_l}$$
$$g_{right} = \frac{x}{x(1-k_r)+k_r}$$

중앙점 $x = t$ 기준으로 좌측 함수는 $0$부터 $a$
중앙점 $x = t$ 기준으로 우측 함수는 $a$부터 $1$ 이 나오도록 
다음의 함수를 구성한다.

$$G(x) = 
\begin{cases} 
a \times g_{left}(\frac{x}{t}) & \text{if } x < t \\
1 + (a - 1) \times g_{right}(\frac{1 - x}{ 1 - t}) & \text{if } x \ge t
\end{cases}$$

중앙점 $x = t$ 에서 미분 값은 다음과 같다.
$$G'(x) = 
\begin{cases} 
\frac{a}{t} \times k_l & \text{if } x < t \\
\frac{1-a}{1-t} \times k_r & \text{if } x \ge t
\end{cases}$$

미분 값을 같게 만들기 위해 다음과 같이 $K$를 조작한다. 
$$k_l =\frac{t(1-a)}{a(1-t)} k_r$$
