
$x_0, x_1,  \dots , x_{n-1}$를 지나는  $n$ 차 다항 함수를 다음과 같이 정의한다.
$$f(x) = (x - x_0)(x - x_1)(x - x_2) \dots (x - x_{n-1})$$

$x$가 중간 지점과 가까울 수록 함수 절대값이 작아지며 
$x_0$ 또는 $x_{n-1}$ 에 가까울 수록 절대값이 커진다.

[[Minimax Approximation]] 
룬게 현상을 극복하기 위해 미니 맥스 상태를 갖는 $n$차 다항 함수를 찾는다.

구간 $[-1, 1]$의 $x$에 대해  
$x = \cos\theta \quad ( 0 \le \theta \le \pi)$  

체비 쇼프 다항식을 다음과 같이 정의한다.
$T_n(x) = \cos(n\theta)$

삼각함수 공식에 의해
$\cos(A + B) = \cos A \cos B - \sin A \sin B$
$\cos(A - B) = \cos A \cos B + \sin A \sin B$
$\cos(A + B) + \cos(A - B) = 2 \cos A \cos B$

$A = n\theta$, $B = \theta$ 를 대입하면
$\cos((n+1)\theta) + \cos((n-1)\theta) = 2 \cos(n\theta) \cos\theta$
$\cos((n+1)\theta) = 2 \cos\theta \cos(n\theta) - \cos((n-1)\theta)$

아래의 관계에 의해
* $\cos((n+1)\theta) = T_{n+1}(x)$
* $\cos\theta = x$
* $\cos(n\theta) = T_n(x)$
* $\cos((n-1)\theta) = T_{n-1}(x)$
점화식을 얻을 수 있다.
$$\mathbf{T_{n+1}(x) = 2x \cdot T_n(x) - T_{n-1}(x)}$$

- $T_0(x) = \cos(0\cdot\theta) = \mathbf{1}$
- $T_1(x) = \cos(1\cdot\theta) = \cos\theta = \mathbf{x}$
* $T_2(x) = 2x^2 - 1$
* $T_3(x) = 4x^3 - 3x$

$T_n(x)$ 은 $n$차 다항식이다. $T_n(x)$의 최고 차항 계수는 $2^{n-1}$ 임으로  
이를 1로 정규화 하면 다음과 같다. $$\tilde{T}_n(x) = \frac{1}{2^{n-1}}T_n(x)$$
$\tilde{T}_n(x) = \frac{1}{2^{n-1}}\cos(n\theta)$ 는 $( 0 \le \theta \le \pi)$ 범위에서
체비 쇼프 극값 ($\frac{1}{2^{n-1}}$ ,  $-\frac{1}{2^{n-1}}$) 이 $n+1$번 번갈아 나열 된다.

최고차항을 제외한 나머지항을 묶어 다음과 같이 표기할 수 있다.
$\tilde{T}_{n}(x) =  x^n - P_{n-1}(x)$ 

이를 오차함수로 보면 
균등 진동 원리에 의해 $P_{n-1}(x)$은 미니맥스 상태가 됨으로

구간 $[-1, 1]$의 $x$에 대해 룬게 현상을 최소화하는 다항식은 $\tilde{T}_{n}(x)$ 이다.

최적의 $n$개 지점 $x_0, x_1,  \dots , x_{n-1}$ 은  $\tilde{T}_{n}(x)=0$ 의 해와 같다. 이를 체비쇼프 노드라고 한다.
$$\cos(n\theta) = 0 \quad ( 0 \le \theta \le \pi)$$
$$n\theta = \frac{\pi}{2}, \quad \frac{3\pi}{2}, \quad \frac{5\pi}{2}, \quad \dots, \quad \frac{2n-1}{2}\pi$$$$\mathbf{\theta_k = \frac{2k+1}{2n}\pi \quad (k = 0, 1, \dots, n-1)}$$$$\mathbf{x_k = \underbrace{-}_{오름 차순 표기}\cos\left( \frac{2k + 1}{2n}\pi \right) \quad (k = 0, 1, \dots, n-1)}$$
 $[-1, 1]$ 구간의 점들을 $[a, b]$ 구간으로 스케일하면 다음과 같다.
$$y = \frac{a + b}{2} + \frac{b - a}{2} x$$
$$y_k = \frac{a + b}{2} - \frac{b - a}{2} \cos\left( \frac{2k + 1}{2n}\pi \right)$$
