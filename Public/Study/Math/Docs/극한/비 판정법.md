
실수열 $(c_n \in \mathbb{R} \setminus \{0\})$ 에 대하여 
무한급수 $\sum_{n=1}^{\infty} c_n$ 에 대하여 다음을 만족할 때 
$$\lim_{n \to \infty} \left| \frac{c_{n+1}}{c_n} \right| = L$$

$L < 1$ 이면, $\sum_{n=1}^{\infty} |c_n|$ 은 절대수렴한다

---
### 증명

가정에 의해 실수 $r$이 존재한다.
$$L < r < 1$$

$\epsilon = r - L > 0$

$\lim_{n \to \infty} \left| \frac{c_{n+1}}{c_n} \right| = L$ 이므로

$\epsilon$ 에 대응하는 자연수 $N \in \mathbb{N}$ 이 존재하여 $\quad (\forall n \ge N)$ 에 대해 다음 부등식이 성립한다.

$$\left| \left| \frac{c_{n+1}}{c_n} \right| - L \right| < \epsilon$$
$$\left| \frac{c_{n+1}}{c_n} \right| < L + \epsilon = r$$
$$|c_{n+1}| < r |c_n|$$
임의의 자연수 $k \ge 1$ 에 대하여 다음을 만족한다.
$$|c_{N+k}| < r^k |c_N|$$
$$\sum_{k=0}^{\infty} |c_{N+k}| = |c_N| + |c_{N+1}| + |c_{N+2}| + |c_{N+3}| + \cdots$$
$$\le |c_N| + r|c_N| + r^2|c_N| + r^3|c_N| + \cdots$$
$$= |c_N| \left( 1 + r + r^2 + r^3 + \cdots \right)$$
$$\sum_{k=0}^{\infty} r^k = \frac{1}{1-r}$$

따라서 다음 부등식이 성립한다:
$$\sum_{k=0}^{\infty} |c_{N+k}| \le \frac{|c_N|}{1-r}$$


$$\sum_{n=1}^{\infty} |c_n| = \underbrace{\sum_{n=1}^{N-1} |c_n|}_{\text{유한한 항들의 합 (유한한 상수 } C\text{)}} + \sum_{k=0}^{\infty} |c_{N+k}|$$
$$\sum_{n=1}^{\infty} |c_n| \le C + \frac{|c_N|}{1-r}$$
$\sum_{n=1}^{\infty} c_n$ 은 절대 수렴한다.
