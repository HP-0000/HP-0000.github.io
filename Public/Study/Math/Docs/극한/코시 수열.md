공간 $X$ 안의 임의의 수열 $\{a_n\} \subseteq X$ 에 대해  다음을 만족하는 경우 코시 수열로 정의한다.
$$(\mathbf{\exists N \in \mathbb{N}}) \land(\forall p, q > N) \quad  |a_p - a_q| < \epsilon$$
수열 $\{a_n\} \subseteq X$ 이 $L \in X$ 로 수렴하면 그 수열은 코시 수열이다. 
$$\lim_{n \to \infty} a_n = L \in X \implies a_n\text{은 코시 수열}$$
임의의 코시 수열 $\{a_n\} \subseteq X$ 이 어떤 $L \in X$ 로 수렴한다면
공간 $X$를 완비 공간으로 정의한다.
$$\lim_{n \to \infty} a_n = L \in X \iff a_n\text{은 코시 수열}$$

수열 $S_n = \sum_{k=1}^n a_k$ 가 수렴한다고 하자.  다음을 만족한다.
$$(\mathbf{\exists N \in \mathbb{N}}) \land ((\forall p, q > N) \quad  |S_p - S_q| < \epsilon$$
$$S_p - S_q = (a_1 + a_2 + \dots + a_p) - (a_1 + a_2 + \dots + a_q) = \mathbf{a_{q+1} + a_{q+2} + \dots + a_p}$$
$$(\forall p, q > N) \quad  \left| \sum_{k=q+1}^{p} a_k \right| < \epsilon$$
$p = q+1$ 를 대입하면
$$|S_{q+1} - S_q| = |a_{q+1}| < \epsilon$$
$|a_{q+1} - 0| < \epsilon$ 임으로,
$$\mathbf{\lim_{n \to \infty} a_n = 0}$$---

$T_n = \sum_{k=1}^n |a_k|$ 가 수렴한다고 하자. 다음을 만족한다.

$$(\mathbf{\exists N \in \mathbb{N}}) \land ((\forall p, q > N) \quad  |T_p - T_q| < \epsilon$$
$$|T_p - T_q| = \mathbf{|a_{q+1}| + |a_{q+2}| + \cdots + |a_p| < \epsilon}$$
$$
|S_p - S_q | = \mathbf{|a_{q+1} + a_{q+2} + \dots + a_p|} \le \mathbf{|a_{q+1}| + |a_{q+2}| + \cdots + |a_p| < \epsilon}
$$
따라서 아래식을 만족함으로
$$(\mathbf{\exists N \in \mathbb{N}}) \land ((\forall p, q > N) \quad  |S_p - S_q| < \epsilon$$
$S_n = \sum_{k=1}^n a_k$ 는 수렴한다.
