아, 죄송합니다! 작성해주신 원본 양식 그대로 **$0$을 $c$로만 정확히 바꿔서** 토씨 하나 안 바꾸고 그대로 적어드리겠습니다.

---

적분 구간을 등간격으로 샘플링한다.
각 점을 3개씩 묶어 2차 곡선으로 근사해 적분한다.

특정 세 점의 좌표를 다음과 같이 두면
* 왼쪽 점: $(c-h, y_0)$
* 가운데 점: $(c, y_1)$
* 오른쪽 점: $(c+h, y_2)$

[[라그랑주 기저 다항식]]

$L_0(x) = \frac{(x - c)(x - (c+h))}{((c-h) - c)((c-h) - (c+h))} = \frac{(x - c)(x - c - h)}{2h^2}$
$L_1(x) = \frac{(x - (c-h))(x - (c+h))}{(c - (c-h))(c - (c+h))} = 1 - \frac{(x - c)^2}{h^2}$
$L_2(x) = \frac{(x - (c-h))(x - c)}{((c+h) - (c-h))((c+h) - c)} = \frac{(x - c + h)(x - c)}{2h^2}$

$$f(x) = y_0 L_0(x) + y_1 L_1(x) + y_2 L_2(x)$$
$$\int_{c-h}^{c+h} f(x) \, dx = y_0 \underbrace{\int_{c-h}^{c+h} L_0(x) \, dx}_{w_0} + y_1 \underbrace{\int_{c-h}^{c+h} L_1(x) \, dx}_{w_1} + y_2 \underbrace{\int_{c-h}^{c+h} L_2(x) \, dx}_{w_2}$$
$w_0 = \int_{c-h}^{c+h} \frac{(x-c)^2 - h(x-c)}{2h^2} \, dx  = \mathbf{\frac{h}{3}}$
$w_1 = \int_{c-h}^{c+h} \left( 1 - \frac{(x-c)^2}{h^2} \right) dx =  4 \times \left(\frac{h}{3}\right)$
$w_2 = \int_{c-h}^{c+h} \frac{(x-c)^2 + h(x-c)}{2h^2} \, dx = \mathbf{\frac{h}{3}}$
$$\int_{c-h}^{c+h} f(x) \, dx = w_0 y_0 + w_1 y_1 + w_2 y_2= \mathbf{\frac{h}{3} \big( y_0 + 4y_1 + y_2 \big)} = \frac{h}{3}[f(c-h) + 4f(c) + f(c+h)]$$

적분하고자 하는 원 함수를 $c$를 기준으로 [[테일러 전개]] 한다.
$$f(x) = f(c) + f'(c)(x-c) + \frac{f''(c)}{2}(x-c)^2 + \frac{f^{(3)}(c)}{6}(x-c)^3 + \frac{f^{(4)}(c)}{24}(x-c)^4 + \cdots$$
$$\mathbf{f(c+h)} = f(c) + f'(c)h + \frac{f''(c)}{2}h^2 + \frac{f'''(c)}{6}h^3 + \mathbf{\frac{f^{(4)}(c)}{24}h^4} + \cdots$$
$$\mathbf{f(c-h)} = f(c) - f'(c)h + \frac{f''(c)}{2}h^2 - \frac{f'''(c)}{6}h^3 + \mathbf{\frac{f^{(4)}(c)}{24}h^4} + \cdots$$
$$\frac{h}{3}[f(c-h) + 4f(c) + f(c+h)] = \mathbf{2h f(c)} + \mathbf{\frac{h^3}{3}f''(c)} + \mathbf{\frac{1}{36}h^5 f^{(4)}(c)} + \cdots$$
원 함수의 적분 식은 다음과 같다.
$$\int_{c-h}^{c+h} f(x) \, dx = \mathbf{2h f(c) + \frac{h^3}{3}f''(c) + \frac{h^5}{60}f^{(4)}(c) + \cdots}$$

앞의 두 항이 같음으로 원 함수의 적분식과 심슨 적분의 오차는 다음과 같다.
$$E(f) = \mathbf{\int_{c-h}^{c+h} R_3(x) \, dx - \frac{h}{3}\Big[ R_3(c-h) + 4R_3(c) + R_3(c+h) \Big]}$$
[적분의 잉여항](/Public/Study/Math/Docs/미적분/적분의%20잉여항)
$$\mathbf{R_3(x) = \frac{1}{6} \int_c^x (x - t)^3 f^{(4)}(t) \, dt}$$

$$\int_c^{c+h} R_3(x) \, dx = \int_c^{c+h} \left( \frac{1}{6} \int_c^x (x - t)^3 f^{(4)}(t) \, dt \right) dx$$

적분 구간이  $c \le x \le c+h$ , $c \le t \le x$  임으로
적분 구간은 $c \le t \le x \le c+h$  이다.

이에 따라 적분 순서를 뒤집어 식을 다시 작성하면
$$\int_c^{c+h} R_3(x) \, dx =  \int_c^{c+h} f^{(4)}(t) \left( \int_t^{c+h} \frac{(x - t)^3}{6} \, dx \right) dt = \int_c^{c+h} \frac{(c + h - t)^4}{24} f^{(4)}(t) \, dt$$

$$\int_{c-h}^c R_3(x) \, dx = \int_{c-h}^c \left( \frac{1}{6} \int_c^x (x - t)^3 f^{(4)}(t) \, dt \right) dx$$
적분 구간이  $c-h \le x\le c$ , $x \le t \le c$ 임으로
적분 구간은 $c-h \le x \le t \le c$  이다.

이에 따라 적분 순서를 뒤집어 식을 다시 작성하면
$$\int_{c-h}^c R_3(x) \, dx =  \int_c^{c-h} f^{(4)}(t) \left( \int_{c-h}^t \frac{(x - t)^3}{6} \, dx \right) dt = \int_c^{c-h} \mathbf{\left( -\frac{(t - c + h)^4}{24} \right)} f^{(4)}(t) \, dt$$

$$\int_{c-h}^c R_3(x) \, dx  = \mathbf{\int_{c-h}^c \frac{(t - c + h)^4}{24} f^{(4)}(t) \, dt} = \int_0^h \frac{(h - s)^4}{24} f^{(4)}(c-s) \, ds$$
$$
\mathbf{\int_{c-h}^{c+h} R_3(x) \, dx = \int_0^h \left[ \frac{(h - s)^4}{24} \right] \Big[ f^{(4)}(c+s) + f^{(4)}(c-s) \Big] \, ds} $$

* $R_3(c) = \frac{1}{6}\int_c^c \dots = 0$
* $R_3(c+h) = \frac{1}{6} \int_c^{c+h} (c+h - t)^3 f^{(4)}(t) \, dt = \frac{1}{6} \int_0^h (h - s)^3 f^{(4)}(c+s) \, ds$
	* $R_3(c-h) = \frac{1}{6} \int_c^{c-h} (c-h - t)^3 f^{(4)}(t) \, dt = \frac{1}{6} \int_0^h (h - s)^3 f^{(4)}(c-s) \, ds$

$$\mathbf{\frac{h}{3}\Big[ R_3(c-h) + 4R_3(c) + R_3(c+h) \Big] = \int_0^h \left[ \frac{h(h - s)^3}{18} \right] \Big[ f^{(4)}(c+s) + f^{(4)}(c-s) \Big] \, ds}$$

$$E(f) = \int_0^h \left[ \mathbf{\frac{(h - s)^4}{24} - \frac{h(h - s)^3}{18}} \right] \Big[ f^{(4)}(c+s) + f^{(4)}(c-s) \Big] \, ds$$
$$E(f) = \int_0^h \left[ \mathbf{-\frac{(h - s)^3 (h + 3s)}{72}} \right] \Big[ f^{(4)}(c+s) + f^{(4)}(c-s) \Big] \, ds$$


구간 $[c-h, c+h]$ 에서  사잇값 정리에 의해  $\frac{f^{(4)}(c+s) + f^{(4)}(c-s)}{2} = f^{(4)}(\xi \mid (c-h, c+h))$  
 
 $0 \le s \le h$ 에서 $-\frac{(h - s)^3 (h + 3s)}{72} \le 0$ 임으로 
 적분의 가중  [평균값 정리](Public/Study/Math/Docs/미적분/평균값%20정리.md)에 의해 

$$E(f) = \mathbf{2f^{(4)}(\xi \mid (c-h, c+h))} \int_0^h \left( \frac{(h - s)^4}{24} - \frac{h(h - s)^3}{18} \right) ds$$
 
$u = h - s$ 
$$\int_h^0 \left( \frac{u^4}{24} - \frac{h u^3}{18} \right) (-du) = h^5 \left( \frac{3 - 5}{360} \right) = \mathbf{-\frac{1}{180} h^5}$$
$$\mathbf{\therefore E(f) = -\frac{1}{90} h^5 f^{(4)}(\xi \mid (c-h, c+h))} $$
전체 구간 $[a, b]$ 에 대해 포물선 $m$개 로 근사한다 
필요한 점의 개수는  $n = 1+2m$ 개이다.
간격 $h$는 다음과 같다.
$$h = \frac{b-a}{n-1} = \frac{b-a}{2m}$$
총 오차는 다음과 같다.

$$E_{\text{total}} = \sum_{i=1}^m E_i = \sum_{i=1}^m \left( -\frac{1}{90} h^5 f^{(4)}(\xi_i \mid (c_i-h, c_i+h)) \right)$$
사잇값 정리에 의해 
   $$f^{(4)}(\mathbf{\xi \mid (\xi_1, \xi_m )}) = \frac{\sum_{i=1}^m f^{(4)}(\xi_i \mid (c_i-h, c_i+h))}{m}$$
$$\mathbf{\sum_{i=1}^m f^{(4)}(\xi_i) = m \cdot f^{(4)}(\xi \mid (a, b))}$$
$$E_{total}(f)  = \mathbf{-\frac{b-a}{180} h^4 f^{(4)}(\xi \mid (a, b))}$$
