집합 $F$와 두 이항 연산 $+$, $\times$ 의 짝 $(F, +, \times)$이 아래의 공리를 만족할 때 체라고 정의한다.

- $(F, +)$가 아벨군
$e_{F,+}$를  제외한 집합 $F \setminus \{e_{F,+}\}$ 에 대해
- $(F \setminus \{e_{F,+}\}, \times)$가 아벨군
- 분배법칙이 성립
  $$\forall a, b, c \in F, \quad a \cdot (b + c) = (a \cdot b) + (a \cdot c)$$
  $$\forall a, b, c \in F, \quad (a + b) \cdot c = (a \cdot c) + (b \cdot c)$$
---
###### 순서체
$\forall a, b, c \in F$에 대해 대소 관계가 존재하여
아래의 공리를 만족할 때 순서체라고 정의한다.

$a \le b \implies a + c \le b + c$
$e_{F,+} \le a \;\land\; e_{F,+} \le b \implies e_{F,+} \le a \times b$

$a \le b \;\land\; b \le a \implies a = b$
$a \le b \;\land\; b \le c \implies a \le c$
$a \le b \;\lor\; b \le a$
###### 완비 순서체
순서체가 아래의 공리를 만족할 때 완비 순서체라고 정의한다.
이러한 체는 실수체($\mathbb{R}$)가 유일하다.

$$\forall \emptyset \neq S \subseteq F, \quad (\exists M \in F, \; \forall x \in S, \; x \le M) \implies \exists \sup S \in F$$

###### 항등원의 대소 비교
정의에 의해 
$$\mathbf{e_{F,\times} \neq e_{F,+}}$$
아래와 같이 가정한다.
$$e_{F,\times} < e_{F,+}$$
양변에 $e_{F,\times}$의 덧셈 역원을 더한다.
$$e_{F,\times} + (-e_{F,\times}) < e_{F,+} + (-e_{F,\times})$$
$$\mathbf{e_{F,+} < -e_{F,\times}}$$
   $$e_{F,+} < (-e_{F,\times}) \times (-e_{F,\times})$$$$\mathbf{e_{F,+} < e_{F,\times}}$$
결론과 가정이 모순임으로 다음이 성립한다.
$$e_{F,+} < e_{F,\times}$$
