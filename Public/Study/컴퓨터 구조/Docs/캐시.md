### RAM ➡️ CPU 캐시
CPU는 캐시 라인 단위(보통 64바이트) 만큼 정해진 경계에서 데이터 블록을 읽어 가져온다.
그래서 만약 필요한 데이터가 캐시라인에 걸치는 경우 두 개를 읽어와야 한다.
### CPU 캐시 ➡️ 레지스터
CPU는 load/store 명령어에 따라 캐시라인에서 데이터를 읽고 레지스터로 전달한다.
데이터가 캐시 라인 또는 명령어가 가리키는 물리적 경계선에 걸친다면 여러번 읽어야 한다.
#### 코어 간 캐시 접근
코어가 캐시 라인을 수정하는 경우,  다른 코어는 해당 캐시라인을 Invalidate 한 뒤, 필요한 경우 다시 가져온다 (다른 코어 캐시 또는 RAM에서).

같은 객체를 멀티 스레드에서 수정할 때, 서로 다른 멤버를 수정하더라도 
같은 캐시라인에 위치하면 캐시 coherence 때문에 invalidate가 발생하여 성능 저하가 생긴다.
