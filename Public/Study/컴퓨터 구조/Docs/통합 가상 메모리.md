CPU와 GPU가 서로 다른 물리적 메모리를 쓰더라도, 하나의 통일된 '가상 주소(Virtual Address)'를 공유하도록 만드는 소프트웨어 기술

CPU의 페이지 테이블에 VA - PA 매핑이 생기면 GTT에도 매핑을 만든다.
이때 GTT는 Present bit 가 0 이며 나머지 비트에는 페이지 테이블에서 Ram PA 를 참조하라는 정보가 인코딩 된다.

GPU가 해당 가상 주소에 접근 하는 경우 페이지 폴트가 발생하고 OS는 비트 패턴으로 판단하여
데이터를 복사 해온 뒤 Present bit 를 1로 올리고 CPU의 페이지 테이블의 Present bit 를 0으로 낮춘다.
마찬 가지로 CPU가 해당 가상 주소에 접근 하는 경우 페이지 폴트가 발생하고 데이터 복제가 발생한다.
