
| 접두사     | 의미                           | 설명 및 예시                      |
| :------ | :--------------------------- | :--------------------------- |
| **`T`** | **T**emplate                 | 템플릿 클래스                      |
| **`F`** | **F**loat (역사적) $\to$ Struct | UObject를 안 타는 일반 C++ 구조체/클래스 |
| **`U`** | **U**Object                  | 가비지 컬렉터가 관리하는 언리얼 오브젝트       |
| **`A`** | **A**ctor                    | 월드(레벨)에 직접 스폰/배치 가능한 객체      |
| **`I`** | **I**nterface                | 추상 인터페이스 클래스                 |
| **`E`** | **E**num                     | 열거형 타입                       |
| **`b`** | **b**oolean                  | 참/거짓 변수                      |
