`UObject` 들은 `UPackage` 단위로 묶인다. 
저장/로드 되는 최소 단위이다.
###### C++ Module
`/Script/<ModuleName>`
###### Engine Asset
`/Engine/<Engine Content 폴더 상대경로>/<PackageName>`
###### Game Asset
`/Game/<Content 폴더 상대경로>/<PackageName>`
###### Plugin Asset
`/<PluginName>/<Plugins Content 폴더 상대경로>/<PackageName>`
###### Object Path
패키지 안의 오브젝트들은 다음의 가상경로를 갖는다.
`<UPackage>.<Uobject>` 
###### Blueprint Class Path 
블루프린트 클래스를 가리킬 때는 접미사 `_C` 가 붙는다.
`<PackagePath>.<ObjectName>_C`
###### SubObject Path
서브오브젝트들은 다음의 가상경로를 갖는다.
`<UPackage>.<Uobject>:<SubObjectName>` 

서브 오브젝트는 깊이에 따라  `.` 을 붙인다.
`<UPackage>.<Uobject>:<SubObjectName>.<SubObjectName>`
###### Transient 
런타임 메모리에만 동적으로 존재하는 UObject 의  임시 가상 경로
`/Engine/Transient`
