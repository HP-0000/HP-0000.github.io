MemoryTrace 는 할당 연산자 오버로딩 및 OS API를 후킹을 통해
할당한 메모리에 대해 MemoryTrace_Alloc를 호출하도록 한다.

MemoryTrace_Alloc는 UE_TRACE_LOG를 호출하며 다음과 같은 정보를 기록한다.
< 주소, 콜 스택, 사이즈, 정렬. > 

정렬 값은 2의 n 거듭 제곱임으로 사이즈와 정렬 값을 바이트 효율적으로 쓰기 위해서 
사이즈의 하위 3비트를 빼고 기록, 사이즈의 하위 3비트와 N값을 비트 패킹 해서 기록 한다.

이렇게 기록된 메모리 정보는 언리얼 인사이트에서 트리 형태로 볼 수 있다.
