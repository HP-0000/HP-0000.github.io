#### Bool
1바이트를 사용하기 때문에 메모리 효율적이지 않다.
클래스 선언 시에는 uint8 타입을 사용하고 비트 필드를 패킹하여 사용한다.
b접두사를 사용한다.

```
Class Exmaple
{
	uint8 bMember1 : 1; 
	uint8 bMember2 : 1;
	void Set(bool bTrue) 
	{ 
		bMember1 = bTrue; // 여기서 자동으로 비트 변환이 일어남 
	}
}
```
#### Tchar
문자열을 UTF-16으로 저장한다.
##### 서로게이트 페어
Tchar 두 개를 사용해서 1,024개( 0xD800 ~ 0xDBFF) ×1,024개(0xDC00 ~ 0xDFFF) 조합을 만들어 
100만개의 문자를 표현한다.
#### FString
`TArray<TCHAR>` 의 래퍼클래스로 문자열 조합, 검색, 자르기 등 로직을 수행할 수 있으나 
인덱스 단위로 데이터를 다루기 때문에 서로게이트 페어의 경우 중간 인덱스를 자르면 데이터가 깨진다.

#### FText
`"Namespace", "Key", "기본 텍스트"` 를 할당하여 만든다.
로컬라이제이션 대시보드를 통해 번역용 엑셀 파일을 자동으로 만든다.
엑셀에 번역 텍스트를 직접 타이핑 해놓으면 언어 설정에 따라 자동으로 텍스트가 할당된다.

#### FName
문자열을 8바이트의 숫자로 치환해서 저장해준다. 문자열 비교 또는 검색에 효과적이다. 
한 번 등록되면 삭제 되지 않는다.
