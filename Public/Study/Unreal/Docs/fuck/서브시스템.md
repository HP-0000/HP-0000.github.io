말하자면 언리얼이 제공하는 스마트 싱글톤이다. 클래스를 선언만 해두면 자동으로 인스턴스를 만들어주고
생명 주기 역시 자동으로 관리된다. 상속해서 작은 싱글톤을 많이 만들어서 의존성도 줄일 수 있다.

| 종류 | 생성 및 소멸 시점 (수명) | 한 줄 요약 |
| :--- | :---: | :--- |
| **UEngine** | 엔진 실행 ~ 종료 | 게임 플레이와 상관없는 글로벌 엔진 기능 |
| **UEditor** | 에디터 켜짐 ~ 꺼짐 | 개발 편의를 위한 에디터 전용 툴 기능 |
| **UGameInstance** | 게임 'Play' ~ 'Stop' | 맵을 옮겨 다녀도 계속 유지되는 전체 데이터 |
| **UWorld** | 맵 로드 ~ 다른 맵 이동 시 | 해당 스테이지(Level) 안에서만 필요한 기능 |
| **ULocalPlayer** | 패드/화면 할당 ~ 제거 시 | 사람(플레이어) 1명에게만 필요한 개인화 기능 |
