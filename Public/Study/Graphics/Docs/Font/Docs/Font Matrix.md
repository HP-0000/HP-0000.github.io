###### Glyph Units Per Em
글자 상자의 해상도.

$$
\text{화면의 출력 픽셀} = \frac{\text{glyph unit}}{\text{upm}} \times \text{Pixel Size}
$$

###### Baseline
글자들이 서 있는 기준 바닥 
###### Ascent
Baseline 기준으로 위로 뻗어 나가는 최대 높이
###### Descent
Baseline 기준으로 아래로 내려가는 최대 깊이
###### Line Gap
줄 간격 여백
###### Line Height
Ascent , Descent, Line Gap(대부분 무시됨) 기준으로 결정되는 줄과 줄 사이의 기본 간격
###### Glyph Width
글자 자체의 너비
###### (Left, Right) Side Bearing
글자 (왼쪽,오른쪽)의 패딩 너비
###### Advance Width
LSB+RSB+ Glyph Width
###### Capital Letter Height
대문자 글자의, 시각적 높이
###### X Height
소문자 글자의, 시각적 높이
###### Overshoot
원이 사각형보다 시각적으로 작아 보이기에 이를 보정하고자
Baseline, Capital Letter Height 를 기준으로 추가로 제공하는 간격
###### Font Weight
폰트의 두께
###### Italic Angle
글자 기울기 각도
