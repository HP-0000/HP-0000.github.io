기존의 PSO 구조체는 모든 상태를 한번에 다 집어 넣으니 그 내용이 비대해진다.
더욱이 신기능에 대해 API 구조체를 계속 만들어 내는 것도 부담이 크다. 

사용자가 필요한 파이프라인 요소를 구조체로 직접 구성할 수 있게 하여 (명시 하지 않은 부분은 기본값 대체), 
PSO를 확장적으로 만들 수 있게 되었다.
