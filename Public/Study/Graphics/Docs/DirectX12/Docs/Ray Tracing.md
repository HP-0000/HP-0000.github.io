광원에서 물체로 물체에서 눈으로의 빛의 이동 경로를 역으로 계산한다.
카메라에서 각 픽셀 방향으로 광선을 쏘아, 가장 가까운 프리미티브와의 교차점을 찾는다.
광원 방향으로 셰도우 레이를 쏘아 차폐되지 않은 경우 더한다.
그리고 해당 교차점의 재질에 따라 

Ray Tracing : 간접광을 찾기 위해 재질의 반사 혹은 굴절 방향으로 다시 광선을 쏘아 새 교차점을 찾는다.
Path Tracing : 간접광을 찾기 위해 반사 방향으로 중요도 샘플링을 하여 광선을 쏘아 새 교차점을 찾는다.

정해진 깊이 만큼 재귀를 마친 다음, 각 결과에 대해 간접광을 전파한다.
