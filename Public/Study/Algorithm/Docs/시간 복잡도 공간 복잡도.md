### 시간 복잡도
데이터가 늘어날 때 연산 횟수의 변화
- O(1)  (상수 시간) : 데이터 상관 없이 한 번에 끝남.
- O(N) (선형 시간) : 데이터 개수만큼 반복함
- O($\log N$) (로그 시간) : 데이터 개수만큼 반복함
### 공간 복잡도
메모리를 얼마나 차지하는가
- O(1)  (상수 공간) : 항상 일정한 메모리만 사용함
- O(N) (선형 공간) : 데이터 개수만큼 메모리가 필요함 ex)배열
- O($\log N$) (로그 공간) : ex) 이진 탐색의 재귀 호출의 스택 메모리

#### Big-O Notation 

N의 증가에 따른 추세를 보기 때문에 상수는 무시한다. 
ex) O($\log N^2$) 은 O($\log N$) 과 같다.

N이 무한이 커질 때 추세를 보기 때문에 작은 항은 무시한다.
ex) O($N^2$) + O(N) 은 O($N^2$) 과 같다.
