###### Pass-by-Value
`template <typename T> void f(T x);`

매개 변수와 인자에 대해 참조, `const`를 제거 후
T를 추론한다.
###### Pass-by-Reference
`template <typename T> void f(T& x);`

매개 변수와 인자에 대해 참조를 제거 후
T를 추론한다.
###### Universal Reference
`template <typename T> void f(T&& x);`

인자가 우측값인 경우, 매개변수에서 참조를 제거 후 `T`를 추론한다.
인자가 좌측값인 경우,  `T`는 인자에 `&`를 붙여 [참조](Public/Study/C++/Docs/참조.md) 축약을 적용한 타입이다.

###### Class Template Argument Deduction
C++17 부터 도입되었다.
컴파일러가 객체 생성 시 생성자에 전달된 인자를 통해 클래스 템플릿의 인자 타입을 추론하여,
템플릿 인자 명시를 생략하게 하여 보일러플레이트를 줄일수 있다.

```cpp
// [C++14 이전] 
std::pair<int, double> p(1, 3.14);
auto p = std::make_pair(1, 3.14);
std::lock_guard<std::mutex> lock(mtx);

// [C++17 CTAD] 
std::pair p(1, 3.14); 
std::lock_guard lock(mtx);
```
###### User-defined Deduction Guide
CTAD 추론 규칙을 커스텀한다.

```cpp
클래스명(입력 인자 패턴) -> 실제 완성할 템플릿<타입>;
```

```cpp
//UDDG
MyBox(const char*) -> MyBox<std::string>;

//UDDG
template <typename T, typename... U>
array(T, U...) -> array<T, 1 + sizeof...(U)>;

MyBox box = "hello"; // MyBox<std::string>
std::array arr = {1, 2, 3}; //  std::array<int, 3>
```
