진짜 객체에 접근하지 말고 대리인을 거치게 한다.

별도의 객체에 대해 내부에 코드를 집어 넣지 않고, 그 객체를 내부에 가지고 있으면서
별도의 무언가를 하는 대리 객체를 만드는 것이다.

처음부터 객체를 다 만들면 느리니까 접근 받으면 내부적으로 객체를 생성하거나,
접근을 제어하기 위해 사용한다.

객체를 감싼다는 점에서는 동일하지만 기능을 계속 덧붙인다는 점에서 다음과 같은 패턴이 있다. 
[Decorator Pattern](Public/Study/C++/Docs/Design%20Pattern/Decorator%20Pattern.md)
