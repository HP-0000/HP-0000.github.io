###### 멤버 변수 포인터
멤버 변수의 타입과 `class::*` 를 합친 타입을 멤버 포인터 라고 한다.
컴파일러는 `&class::member`문법으로 객체 시작점에서 얼마나 떨어져 있는지 오프셋을 계산해 
멤버 포인터에 대입한다.

```cpp
struct Player {
    std::string name;
    int hp;

    void Heal(int amount) {
        hp += amount;
        std::cout << name << " 회복됨! 현재 HP: " << hp << "\n";
    }
};
```

```cpp
int Player::* ptr_hp = &Player::hp;
```

`.*` 그리고 `->*` 연산자를 통해 접근한다.
```cpp
Player p1{"전사", 100};
p1.*ptr_hp = 150; 

Player* p2 = new Player{"마법사", 80};
p2->*ptr_hp = 90; 
```
###### 멤버 함수 포인터
문법은 다음과 같다.
```cpp
리턴타입 (class::*변수명)(파라미터...)
```

```cpp
void (Player::* ptr_heal)(int) = &Player::Heal;
```

다음과 같이 괄호로 우선순위를 명시한 뒤 호출한다.
```
(객체.*포인터)(인자) 
```
```cpp
Player p1{"전사", 100};
(p1.*ptr_heal)(30); 
```

###### std::invoke
위 방식은 문법이 끔찍함으로 한 단계 래핑하여 호출하듯 사용할 수 있게 만들었다.

```cpp
#include <functional> 
Player p1{"전사", 100};

// 멤버 변수 
auto ptr_hp = &Player::hp;
int current_hp = std::invoke(ptr_hp, p1); 
std::invoke(ptr_hp, p1) = 10;

// 멤버 함수 
auto ptr_heal = &Player::Heal;
std::invoke(ptr_heal, p1, 50);
```
