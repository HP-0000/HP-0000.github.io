컴파일러는 코드를 왼쪽에서 오른쪽으로 읽음으로 메타 프로그래밍시 컴파일 에러가 생긴다.

[decltype](Public/Study/C++/Docs/decltype.md)
```cpp
// c[index] 가 뭔지 모름, ❌ 컴파일 에러 발생!
template <typename Container>
decltype(c[index]) Get(Container& c, int index) 
{
    return c[index];
}
```

다음과 같이 반환 타입을 화살표를 통해 오른쪽에 명시한다. 
```cpp
// 앞엔 auto만 두고, 뒤에 화살표로 리턴 타입 명시
// ✅ 컴파일 성공!
template <typename Container>
auto Get(Container& c, int index) -> decltype(c[index])
{
	return c[index];
}
```
