선언된 기본 템플릿에 대해 특수화된 구현을 제공하여
컴파일러가 후보들 중 가장 구체적인 구현을 우선 선택하도록 한다.
[Substitution_Failure_Is_Not_An_Error](Public/Study/C++/Docs/Compile/Substitution_Failure_Is_Not_An_Error.md)
###### 특수화 우선순위
1 순위 : 명시적 특수화
2 순위 : 부분 특수화
3 순위 : 인자의 개수와 구체성
###### 기본 템플릿 
```cpp
template <typename T, int N>
struct MyTool;
```

- < > 선언부의 식별자 `T`에는 참조, `*`, `const` 를 붙여 선언할 수 없다.
- < > 에는 [Non-Type Template Parameter](Public/Study/C++/Docs/Compile/Non-Type%20Template%20Parameter.md)을 선언 할 수 있다.
- 특수화 시 `<...>` 안의 인자 개수는 기본 템플릿 틀과 동일해야 함.
###### 명시적 특수화 (Explicit Specialization)
모든 템플릿 인자들을 구체화
```cpp
template <>
struct MyTool<int, 7>; // T는 int
```
###### 부분 특수화 (Partial Specialization)
일부 템플릿 인자들을 구체화
```cpp
template <typename T>
struct MyTool<T, 7>;
```
```cpp
template <typename T>
struct MyTool<T*, 7>; // T는 포인터
```
함수는 오버로딩이 존재하기에 부분 특수화 문법이 지원되지 않는다.
```cpp

template <typename T> void print(T x);   // 기본 템플릿
template <typename T> void print(T* x); // 오버 로딩
template <typename T> void print<T*>(T* x); // ❌ 컴파일 에러
```
