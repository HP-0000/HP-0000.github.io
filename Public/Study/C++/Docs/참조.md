[값](Public/Study/C++/Docs/값.md)에 식별성을 부여한다.

`prvalue` 의 경우 임시 객체로 생성되어 자신이 속한 표현식의 끝`;`에서 소멸된다.
참조를 통해 식별성을 부여하여 참조가 갖는 스코프로 수명을 연장 할 수 있다.

참조의 경우 선언과 동시에 값을 바인딩해야 하며 이후 대상을 변경할 수 없다.
수명 연장의 경우 최초로 바인딩한 참조자에만 국한된다.

바인딩되는 객체의 수명이 해당 클래스 인스턴스보다 더 길다는 것이 보장될 때,
클래스의 멤버 변수로 참조를 사용한다. 
###### 좌측값 참조
```cpp
T x;
T& ref = x;
```

`ref` 는 참조 변수로써 별도의 메모리 할당 없이 `x`의 식별자로서 쓰이며
컴파일시 지역 변수로 사용되었을 경우 `x` 자체로 치환된다.

함수 매개변수나 클래스 멤버 변수에 선언될 경우만 
메모리가 할당되어 포인터를  만들어 `x` 의 주소를 담는다.

```cpp
T y;
ref = y;
```
`x` 의 복사 대입 연산자가 호출된다.

```cpp
T val = ref;
```
`val`의 복사 생성자에 `x` 가 전달 된다.

```cpp
const T& ref = T(params);
```
`const` 는 이동성을 제한함으로 우측값을 좌측값 참조로 나타낼 수 있다.
###### 우측값 참조

```cpp
T x(params); // lvalue
T&& ref = (T&&)x; // xvalue 
```

마찬가지로 `ref` 는 참조 변수로써 별도의 메모리 할당 없이 `x`의 식별자로서 쓰이며 컴파일시 지역 변수로 사용되었을 경우 `x` 자체로 치환된다.

함수 매개변수나 클래스 멤버 변수에 선언될 경우만 
메모리가 할당되어 포인터를  만들어 `x` 의 주소를 담는다.

```cpp
T&& ref = T(params); //prvalue 
```

`T(params)` 는 임시 객체로서 메모리에 할당되며 `ref`는 해당 주소의 식별자로서 사용된다.

###### 값 반환
caller는 스택에 반환 값에 대한 메모리를 할당하고 이를 callee로 전달한다. 
callee는 넘겨 받은 주소에 생성자를 호출하여 객체를 완성한다.

```cpp
T Return()
{
	return T(params);
}

T&& ref = Return();
```
caller의 스택에 임시 객체 메모리를 생성해 callee로 전달한다.
`ref` 는 해당 임시 객체 메모리에 식별자를 부여해 수명을 연장한다.
 
```cpp

T Return()
{
	T x(params);
	return x;
}

T val = Return();
```
callee의 `return` 값에 함수에 선언된 지역 변수인 `lvalue` 를 사용하는 경우
Named Return Value Optimization 가 수행된다.

caller에 잡힌 val 스택 메모리를 넘겨받은 callee는 그 주소를 사용해
lvalue 를 생성한다.

Named Return Value Optimization를 수행하지 못할 경우, `lvalue`를 암시적으로 우측 값으로 취급해
callee는 'val' 주소에 이동 생성자를 우선적으로 호출하고 
이동 생성자가 없는 경우 복사 생성자를 호출한다.

```cpp
T Return()
{
	return T(params);
}

T val = Return();
```

C++ 17 부터 도입된 Guaranteed Copy Elision 규약에 따라 
`return` 값에 `prvalue` 를 사용하는 경우
callee는 `val` 메모리를 이용해 직접 생성자를 호출한다.

###### 좌측값 참조 반환
```cpp
T& Return()
{
	static T x;
	return x;
}

T& ref = Return();
```
 caller 의 `ref` 는 스택 메모리에서 포인터로 잡히며 `x` 의 주소가 전달 된다.

```cpp
T val = Return();
```

callee는 `x`의  주소를 레지스터를 통해 caller로 전달하고
caller는 스택에 `val` 객체 메모리를 잡고 `x` 로 부터 복사 생성자를 호출한다.
###### 우측값 참조 반환
```cpp
T&& Return()
{
	static T x(params);
	return (T&&)x;
}
T&& ref = Return();
```
 caller 의 `ref` 는 스택 메모리에서 포인터로 잡히며 `x` 의 주소가 전달 된다.
 
```cpp
T val = Return();
```

callee는 `x`의  주소를 레지스터를 통해 caller로 전달하고
caller는 스택에 `val` 객체 메모리를 잡고 `x` 로 부터 이동 생성자를 호출한다.

---
###### Named Return Value Optimization 주의 할점
디버그의 경우 최적화가 꺼지며 NRVO가 수행되지 않고
릴리즈의 경우 수행된다.

또한 다음의 경우 이동 생성자를 강제하면서 NRVO를 수행하지 않게 된다.
```cpp
T Return()
{
	T x(params);
	return (T&&)x;
}

T val = Return();
```
따라서 모든 생성자의 호출 여부와 상관없이 일관되게 동작하도록 설계해야 한다.

###### 참조 한정자
함수 뒤에 참조자를 붙여 임시 객체의 여부에 따라 동작을 구현할 수 있다. 


```cpp
class BigData
{
    std::string text = "Huge Data...";
public:
    std::string GetText() & 
    {
        return text;
    }

    std::string GetText() && 
    {
        return std::move(text);
    }
};
```

```cpp
BigData data;
data.GetText(); // (&) 호출
BigData().GetText(); // (&&) 호출
```

 ###### 참조 축약 규칙
[타입 별칭](Public/Study/C++/Docs/타입%20별칭.md) 과 템플릿에 의해 참조가 중첩될 때 
컴파일러가 병합하는 규칙.
* `&` + `&` $\rightarrow$ `&`
* `&` + `&&` $\rightarrow$ `&`
* `&&` + `&` $\rightarrow$ `&`
* `&&` + `&&` $\rightarrow$ `&&`
