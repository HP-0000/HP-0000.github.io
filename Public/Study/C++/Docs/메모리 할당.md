가상 메모리를 할당받는 방식은 다음과 같다.

```text
VirtualAlloc  (Windows API)
  ↓ 페이지(4KB~) OS한테 직접 메모리 페이지 요청
  
HeapAlloc  (Windows API)
  ↓ VirtualAlloc으로 받은 걸 잘게 나눠서 관리

malloc  (C 표준)
  ↓ HeapAlloc을 감싼 표준 인터페이스

operator new  (C++)
  ↓ malloc + 생성자 호출
```
#### Placement New
메모리 주소에 직접 객체를 생성한다.
```cpp
new (메모리 주소) Class()
```

# 프로세스 메모리 할당

###### 코드 영역
컴파일된 기계어가 담긴다.
`.exe` 실행 시 OS 로더가 파일의 바이너리를 그대로 메모리에 올린다.
###### Data 영역
초기값이 있는, 전역 변수와 `static` 변수 그리고 문자열은`.exe` 파일 안에 
두 가지 영역으로 나뉘어 값이 저장되며 각각 페이지를 할당 받는다.
- .data 영역 : 수정 가능
- .rdata 영역 : 수정 불가능  
###### BSS 영역
초기값이 없는, 전역 변수와 `static` 변수에 할당된다.
`.exe` 파일에는 할당 해야 할 전체 크기가 저장되고
파일이 켜질 때, OS 로더가 페이지를 할당하고 0으로 초기화 한다.
###### 힙(Heap) 영역
프로그램이 실행될 때, 힙 매니저가 기본적으로 페이지를 할당받아 둔다.  
런타임에 프로그래머가 직접 동적으로 할당하고 해제(new, malloc)하는 메모리 영역이다.
힙 매니저가 중간에서 자동으로 저장 공간을 동적으로 늘리거나 줄여 관리한다.
###### 스택(Stack) 영역
함수의 지역 변수, 매개변수, 복귀할 반환 주소가 저장되며, 스레드마다 독립적으로 할당된다.
연속된 가상주소를 사용해 메모리가 선형적(LIFO)으로 단순하게 입출력되어 
CPU 캐시 적중률이 높고, 힙 매니저를 거치지 않아 할당 및 해제 속도가 압도적으로 빠르다.
반면 최대 크기가 고정되어 정해진 한도를 초과하면 스택 오버플로우(Stack Overflow)가 발생한다.
###### TLS 영역
thread_local 키워드가 붙은, 전역 변수와 `static` 변수에 할당된다.
스레드가 생성되면 OS가 메모리를 할당하며 파괴되면 회수한다.
