###### deque(Double-Ended Queue)
양방향에서 삽입과 삭제가 가능하며 임의 접근이 가능한 컨테이너

고정 크기 메모리 블록을 할당받아 그 주소를 배열 형태로 관리한다.
재 할당시 기존의 배열 중앙이 새 배열의 중앙으로 배치되어
양방향에 빈자리를 만들고 내부적으로 요소의 시작 주소를 추적하고 있어 
기존의 인덱스를 유지한다.
###### queue
`deque` 를 래핑하여 `FIFO(First-In, First-Out)` 구조를 사용하도록 제한하는 컨테이너 어댑터

###### stack
`deque` 를 래핑하여 `LIFO(Last-In, First-Out)` 구조를 사용하도록 제한하는 컨테이너 어댑터
