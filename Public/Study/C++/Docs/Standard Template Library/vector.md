선형 메모리를 할당한다.

`capacity`는 할당된 메모리를 나타내며
`size` 는 할당된 메모리에 할당된 요소의 개수를 나타낸다.
`size` 가 `capacity` 와 같아지는 경우, 요소를 넣으려하면 동적으로 재할당이 발생한다.
기존의 모든 요소를 새 메모리로  이동, 복사 생성한다.
기존의 메모리의 모든 요소의 소멸자를 호출한 뒤 반환한다.
###### pop_back
마지막 요소의 소멸자를 호출한다. `size`를 1 줄인다.
###### clear
모든 요소의 소멸자를 호출하고 `size`를 0으로 만든다.
###### erase
지정한 범위 뒤의 요소들을 앞으로 이동 대입, 복사 대입한다.
삭제된 개수만큼 맨 뒤쪽 요소들의 소멸자를 호출하고 `size`를 줄인다.

---
###### `push_back(val)`
맨 뒤에 원소를 삽입한다.
[값](Public/Study/C++/Docs/값.md)
`Lvalue` 를 제공하는 경우 복사 생성자가 호출되며
`xvalue` 를 제공하는 경우 이동 생성자를 호출한다.
`prvalue` 를 제공하는 경우 스택에 객체를 생성 후 이동 생성자를 호출한다.
###### `insert(pos, val)`
지정한 반복자 위치에 원소를 삽입한다.
값 전달 방식은 `push_back` 과 동일 하다.
끝에서 부터 요소들을 뒤로 이동 대입, 복사 대입한다. $O(N)$ 의 오버헤드를 발생 시킨다.
###### `emplace_back(params...)`
맨 뒤에 원소를 삽입한다.
생성자의 파라미터만 넘겨받아 스택에 임시 객체를 거치지 않고 생성자를 직접 호출한다.
###### `emplace(pos, params...)`
지정한 반복자 위치에 원소를 삽입한다.
값 전달 방식은 `emplace_back` 과 동일 하다.
끝에서 부터 요소들을 뒤로 이동 대입, 복사 대입한다. $O(N)$ 의 오버헤드를 발생 시킨다.
