`Red-Black Tree` 로 구현된다.
노드는 [pair](Public/Study/C++/Docs/Standard%20Template%20Library/pair.md) 로 `operator<` 가 구현된 `key` 와 `data`를 갖는다.
각 노드는 빨간색 또는 검은색을 가지며 부모와 좌, 우 자식 포인터를 갖는다.

---
* $N$ : 새로 삽입되었거나, 현재 규칙 위반이 발생한 기준 노드
* $P$ : $N$의 부모 노드 
* $G$  : $P$의 부모 노드
* $U$ : $G$의 자식 중 $P$가 아닌 다른 쪽 자식 노드
###### 규칙
루트 노드는 검은색이다.
새로 삽입되는 노드 $N$은 항상 `RED`로 초기화한다.
빈 노드는 `BLACK` 취급 한다.
노드가 `RED`면, 그 노드의 자식들은 반드시 `BLACK` 이다.
루트부터 모든 끝 노드까지 가는 경로의 `BLACK` 개수는 전부 같아야 한다

---
노드를 삽입 후 부모의 색깔 변수가 `RED` 인지 검사한다.

검사 결과가 참이라면 복구는 $U$ 의 색상을 기준으로 두 가지 경로로 분기된다.
```text
                  [ G ]
                 /     \
             [ P ]     [ U ]
             /
          ( N )
```
###### $U$ 의 색상이 `RED`인 경우
$P$와 $U$의 색상을 `BLACK` 으로 변경한다.
$G$의 색상을 `RED`로 변경한다.
$G$ 를 $N$ 으로 삼아 다시 검사를 실시한다.

###### $U$ 의 색상이 `BLACK`인 경우
구조적 불균형을 해소하기 위해 다음과 같이 회전 조정을 수행한다.
###### RightRotate
```text
[ 회전 전 ]                               [ 회전 후 ]

         parent                                    child
        /      \                                  /     \
     child      (C)      ===> 우회전 ===>        (A)    parent
    /     \                                            /      \
  (A)     (B)                                        (B)      (C)
```
###### LeftRotate
```text
[ 회전 전 ]                               [ 회전 후 ]

        parent                                     child
       /      \                                   /     \
     (A)     child       ===> 좌회전 ===>       parent   (C)
            /     \                             /     \
          (B)     (C)                         (A)     (B)
```

| 분류     | 부모($P$)의 위치     | 현재 노드($N$)의 위치  |
| :----- | :-------------- | :-------------- |
| **LL** | $G$의 **왼쪽** 자식  | $P$의 **왼쪽** 자식  |
| **RR** | $G$의 **오른쪽** 자식 | $P$의 **오른쪽** 자식 |
| **LR** | $G$의 **왼쪽** 자식  | $P$의 **오른쪽** 자식 |
| **RL** | $G$의 **오른쪽** 자식 | $P$의 **왼쪽** 자식  |

* LL인 경우
 `RightRotate(G)` 을 수행하고 
 $P$의 색상을 `BLACK`으로, $G$ 의 색상을 `RED`로 변경

* RR인 경우
`LeftRotate(G)`을 수행하고 
$P$의 색상을 `BLACK`으로, $G$의 색상을 `RED`로 변경

* LR인 경우
`LeftRotate(P)`을 수행하고
`RightRotate(G)`을 수행하고
$N$의 색상을 `BLACK`으로, $G$의 색상을 `RED`로 변경

* RL인 경우
`RightRotate(P)` 을 수행하고
`LeftRotate(G)`을 수행하고
$N$의 색상을 `BLACK`으로, $G$의 색상을 `RED`로 변경

---

삽입, 탐색, 제거에 대해 $O(\log N)$ 의 시간 복잡도를 갖는다.
