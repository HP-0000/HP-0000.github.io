###### 컴파일 타임 상수 치환
```cpp
template <typename T>
constexpr bool is_pointer_v = false;

template <typename T>
constexpr bool is_pointer_v<T*> = true; 
```
###### 전역 변수 생성
```
template <typename T> 
T global_counter;


global_counter<int> = 0;
global_counter<int> += 3;

global_counter<double>;
global_counter<double> = 3.14;
```
###### static 변수 생성
```cpp
struct Math 
{
    template <typename T>
    static constexpr T pi = T(3.14159265358979323846L);
};

float  f = Math::pi<float>;
double d = Math::pi<double>;
```
