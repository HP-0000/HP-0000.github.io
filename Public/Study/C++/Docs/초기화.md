###### Default-initialization
`T x;`
###### Value-initialization
`T x{};`
기본 생성자를 호출하며, 선언되지 않은 경우, 생성된 객체의 내부 값을 초기화 해준다.

---
`params` 의 [값](Public/Study/C++/Docs/값.md)에 따라 다음과 같이 동작한다.
###### lvalue 
복사 생성자 호출
###### xvalue 
이동 생성자 호출
###### prvalue
복사,이동 없이 목적지 메모리에 생성

```cpp
class Reference
{
    // 기본 생성자
    Reference();
    // 이동 생성자
    Reference(Reference&& other) noexcept;
    // 복사 생성자 
    Reference(const Reference& other);
};

Reference&& refer = Reference(); // 기본 생성자 호출
Reference Test1 = refer; // refer 은 좌측값임으로 복사 생성자 호출
Reference Test2 = static_cast<Reference&&>(refer); //xvalue 임으로 이동 생성자 호출!
```
###### Direct-initialization
`T x( params );`
###### Copy-initialization
`T x = params;`

암시적 변환에 의해 
`Direct-initialization` 또는 `Aggregate initialization` 를 호출한다.
###### Aggregate initialization
`T x {params};`
`T x[]{params};`

`User-declared` 생성자가 존재하지 않는 경우 호출된다.
`public` 으로 다중 상속을 받았을 경우, 가상 함수를 갖지 않는다면
인자 순서대로 부모들의 생성자를 호출한다. 

그 다음 순서로 자신의 멤버 변수 객체의 생성자를 호출하거나 값을 초기화 하는데
`static` 키워드 변수들은 무시되며, `public` 접근자가 아닌 변수가 존재하는 경우 
컴파일 에러를 발생시킨다.
###### List-initialization
`T x{ params };`
생성자가 존재하는 경우 호출 된다. Narrowing이 감지되면 컴파일 오류를 낸다.
