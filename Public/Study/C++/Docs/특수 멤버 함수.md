### 암시적 생성
`User-declared` 하지 않은 경우. 컴파일러가 암묵적으로 생성 해주는 함수
`=default` 를 선언해 컴파일러에게 암시적  구현을 명시적으로 요청할 수 있으며 
`=delete` 를 선언해 컴파일러에게 암시적 구현 및 함수 호출을 금지함을 명시할 수 있다.

람다 객체의 경우
소멸자와, 이동 생성자, 복사 생성자를 암묵적으로 생성하며
나머지는 특수 멤버 함수들은 원칙적으로 `delete` 된다.
### 암시적 생성 억제
###### 기본 생성자 
`User-declared` 된 생성자가 존재하는 경우
###### 이동 생성자
소멸자, 복사 생성자, 복사 대입 연산자, 이동 대입 연산자를 하나라도 
`User-declared` 한 경우
###### 이동 대입 연산자
소멸자, 복사 생성자, 복사 대입 연산자, 이동 생성자를 하나라도 
`User-declared` 한 경우
###### 소멸자
`User-declared` 된 소멸자가 존재하는 경우
### 암시적 삭제 (`= delete`)
###### 기본 생성자
* 부모 클래스 또는 멤버 변수의 기본 생성자가, 없거나 `private`인 경우
* 기본값 초기화가 안 된 `const` 멤버 변수가 존재하는 경우
* 기본값 초기화가 안 된 참조 멤버 변수가 존재하는 경우
###### 소멸자
* 부모 클래스 또는 멤버 변수의 소멸자가, 없거나 `private`인 경우
###### 복사 생성자
* 부모 클래스 또는 멤버 변수의 복사 생성자가, 없거나 `private`인 경우
* 부모 클래스 또는 멤버 변수의 소멸자가, `private` 또는 `= delete`인 경우
- 이동 생성자, 이동 대입 연산자를 하나라도 `User-declared` 한 경우

* 참조 멤버 변수가 존재하는 경우
* 부모 클래스 또는 멤버 변수의 소멸자가, `private` 또는 `= delete`인 경우
- 이동 생성자, 이동 대입 연산자를 하나라도 `User-declared` 한 경우

* 부모 클래스 또는 멤버 변수의 소멸자가, `private` 또는 `= delete`인 경우
###### 이동 대입 연산자
* 부모 클래스 또는 멤버 변수 중 이동 대입 연산자 또는 복사 대입 연산자가, 없거나 `private`인 경우

* 부모 클래스 또는 멤버 변수의 소멸자가, `private` 또는 `= delete`인 경우

암시적 삭제에 관한 이상적인 설계에는 다음과 같으나 과거와의 호환성을 위해 지원되지 않는다. 
###### 복사 생성자

* 부모 클래스 또는 멤버 변수의 소멸자가, `private` 또는 `= delete`인 경우

###### 복사 대입 연산자
* 부모 클래스 또는 멤버 변수 중 복사 대입 연산자가, 없거나 `private`인 경우
* `const` 멤버 변수가 존재하는 경우
* 참조 멤버 변수가 존재하는 경우
* 부모 클래스 또는 멤버 변수의 소멸자가, `private` 또는 `= delete`인 경우
- 소멸자, 이동 생성자, 이동 대입 연산자, 복사 생성자를 하나라도 `User-declared` 한 경우

### 이동과 복사의 유연성 
객체에 이동 연산자가 정의되어 있지 않다면
`const T&` 는 우측값을 참조할 수 있음으로 복사 연산자가 호출될 수 있다.

### 암시적 구현 
```cpp
struct Derived : public Base1, Base2 
{
    Member1 m1;
    Member2 m2;
    int raw_val;
};
```
###### 기본 생성자 (Default Constructor)
상속 선언 순서대로 부모들의 기본 생성자를 호출하고
선언 순서대로 멤버 객체들을 기본 생성자를 호출한다. 
```cpp
Derived() 
    : Base1(), Base2(), m1(), m2()
{}
```
###### 소멸자 (Destructor)
멤버 객체들의 소멸자를 선언 역순으로 호출하고
상속 역순으로 부모들의 소멸자를 호출한다.
```cpp
~Derived() {
    // 1. 멤버 객체 소멸 (선언 역순: m2 -> m1)
    m2.~Member2();
    m1.~Member1();

    // 2. 부모 소멸자 호출 (상속 역순: Base2 -> Base1)
    Base2::~Base2();
    Base1::~Base1();
}
```
###### 복사 생성자 (Copy Constructor)
상속 선언 순서대로 부모들의 복사 생성자를 호출하고
선언 순서대로 멤버 객체들의 복사 생성자를 호출한다. 
```cpp
Derived(const Derived& other) 
    : Base1(other), 
      Base2(other), 
      m1(other.m1), 
      m2(other.m2), 
      raw_val(other.raw_val) 
{}
```
###### 복사 대입 연산자 (Copy Assignment Operator)
상속 선언 순서대로 부모들의 복사 대입 연산자를 호출하고
선언 순서대로 멤버 객체들의 복사 대입 연산자를 호출한 뒤 `*this`를 반환한다.
```cpp
Derived& operator=(const Derived& other) 
{
    // 1. 부모 복사 대입 (Base1 -> Base2)
    Base1::operator=(other);
    Base2::operator=(other);

    // 2. 멤버 복사 대입 (m1 -> m2 -> raw_val)
    this->m1 = other.m1;
    this->m2 = other.m2;
    this->raw_val = other.raw_val;
    
    // 3. 반환
    return *this;
}
```
###### 이동 생성자 (Move Constructor)
상속 선언 순서대로 부모들의 이동 생성자를 호출하고
선언 순서대로 멤버 객체들의 이동 생성자를 호출한다.
```cpp
Derived(Derived&& other) noexcept
    : Base1(std::move(other)), 
      Base2(std::move(other)), 
      m1(std::move(other.m1)), 
      m2(std::move(other.m2)), 
      raw_val(other.raw_val) 
{}
```
###### 이동 대입 연산자 (Move Assignment Operator)
상속 선언 순서대로 부모들의 이동 대입 연산자에 
`std::move(other)`를 넘겨 호출하고
선언 순서대로 멤버 객체들의 이동 대입 연산자를 호출한 뒤 `*this`를 반환한다.
```cpp
Derived& operator=(Derived&& other) noexcept {
    // 1. 부모 이동 대입 (Base1 -> Base2)
    Base1::operator=(std::move(other));
    Base2::operator=(std::move(other));
    // 2. 멤버 이동 대입 (m1 -> m2 -> raw_val)
    this->m1 = std::move(other.m1);
    this->m2 = std::move(other.m2);
    this->raw_val = other.raw_val;
    // 3. 반환
    return *this;
}
```
