템플릿은 실제 인스턴스화 하는 코드를 발견하면 
해당 시점에 컴파일러가 코드를 생성하며, 이를 위해서는
컴파일러가 구현부를 온전히 알고 있어야하므로

h 파일에 구현부까지 포함해야한다.
인라인 함수의 경우에도 마찬가지 이다.

가독성의 문제로 구현부를 분리하고 싶으면 다음과 같은 패턴을 사용한다.

```cpp
// MyClass.h
#pragma once

template <typename T>
class MyClass {
public:
    void printData(T data); // 1. 선언만 깔끔하게 둡니다.
};

// 2.헤더 맨 마지막에 구현부 파일을 include 합니다!
#include "MyClass.inl"
```

```cpp
// MyClass.inl

// 3. 실제 템플릿의 구현부를 여기에 작성합니다.
template <typename T>
void MyClass<T>::printData(T data) {
    std::cout << data << std::endl;
}
```
