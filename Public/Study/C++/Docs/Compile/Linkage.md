컴파일된 `cpp` 는 바이너리 심볼 테이블에 다음의 속성을 만들어  `.obj` 파일에 저장한다. 
링커는 모든 `.obj` 파일을 훑어 바이너리 심볼 테이블을 확인하여 동작한다.

`UNDEF`
컴파일러는 현재 파일에 정의된 심볼은 바이너리 오프셋을 저장하지만 
선언만 있고 정의가 없는 심볼은 `UNDEF` 플래그를 세워 저장한다.
재배치 테이블에 해당 심볼과 임시 주소를 적어두면, 이후 링커가 실제 주소를 찾아 연결한다.

- `extern` 키워드가 붙은 선언이나 외부 함수 호출 시 해당 속성을 갖는다.

`LOCAL`
링커는 해당 주소를 외부로 노출하지 않는다. 오직 해당 `.obj` 파일 안에서만 유효하다. 
- 전역 스코프에서 `static` 키워드가 붙은 변수나 함수가 해당 속성을 갖는다. 
  헤더 파일에 둘 경우, 인클루드한 `.cpp`마다 독립된 메모리가 따로 생성된다.

`GLOBAL`
링커는 해당 주소를 외부에 노출하여 다른 `.obj` 파일의 `UNDEF`를 해결해 준다. 
프로그램 전체에서 이름이 유일해야 하며, 둘 이상 존재하면 링커 충돌 에러가 발생한다.
- `.cpp` 파일에 정의된 일반 전역 변수나 함수가 해당 속성을 갖는다.

`WEAK`
링커는 여러 `.obj` 파일에 중복된 주소가 있더라도 충돌 에러를 내지 않고
단 하나로 병합(Merge)한다.
- 템플릿 코드나, `inline` 키워드가 붙은 전역 변수나 함수가 해당 속성을 갖는다.
