함수 호출 시 컴파일러는 해당 클래스 타입의 심볼 테이블을 보고 함수 이름을 찾는다.
매개변수가 달라도 같은 이름의 함수를 발견한다면 오버로딩된 함수 후보 목록을 작성한다.
부모 클래스를 탐색하지 않고 작성된 후보 중에서만 매개변수가 일치하는 함수를 찾는다 

```cpp
class FParent {
public:
    // 부모는 숫자를 받는 함수를 가지고 있음
    void Move(int32 X);
};

class FChild : public FParent {
public:
    // 자식이 이름은 같은데 매개변수가 다른 함수를 새로 만듦
    void Move(FString Name);
};
```

```cpp
FChild Child;
Child.FParent::Move(10); // OK:
Child.Move(10); // 컴파일 에러
```

부모의 이름이 가려져 바로 호출할 수 없다.

```cpp
class FChild : public FParent {
public:
    using FParent::Move; 
    void Move(FString Name);
};

void Test() {
    FChild Child;
    Child.Move(10); // OK: 
}
```

`using` 을 통해 부모의 함수를 자식 타입의 심볼 테이블에 추가하여
오버로딩 후보 목록에 포함하여 컴파일러의 이름 가리기 규칙을 우회할 수 있다.
