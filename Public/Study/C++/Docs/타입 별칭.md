###### `typedef`
`typedef`는 코드의 가독성을 위해 복잡한 타입에 별칭을 붙이는 데 사용된다. 
```cpp
typedef std::vector<int> IntVector;
IntVector myVec; 
```
C++11 이후 `using`으로 대체되었다.
###### `using` 
템플릿에도 별칭을 지원한다.

```cpp
using IntVector = std::vector<int>;
IntVector myVec;

template <typename T>
using SmartPointer = std::unique_ptr<T>;
SmartPointer<int> myIntPtr = std::make_unique<int>(42);
```

###### `typename`
템플릿의 별칭으로 인해 템플릿 매개변수(T)에 의존하는 내부 멤버(T::...)는 
컴파일러가 타입인지 static 변수인지 구분하지 못하고 변수로 취급한다.  

`typename`을 사용하여 타입임을 명시한다.
```cpp
template <typename T>
void doSomething(T arg) 
{
    typename T::InnerType myObject;
}
```
