# 2의 거듭제곱 

2의 거듭제곱에 대해서는 덧셈, 뺄셈, 곱셈 모두 비트 연산으로 빠르게 처리할 수 있다.
###### 비트 규칙이 단순하다 ($n$번째 자리수에 1)
- $2^1 = 2 = 0010_2$
- $2^2 = 4 = 0100_2$
- $2^3 = 8 = 1000_2$
- $2^4 = 16 = 10000_2$
###### 1을 빼도 단순하다(뒤에서 부터 1이 정확히 $n$개)
- $2^1 -1 = 1 = 0001_2$
- $2^2 -1 = 3 = 0011_2$
- $2^3 -1 = 7 = 0111_2$
- $2^4 -1 = 15 = 01111_2$

**덧셈**
 $2^n$ 과 그보다 작은 수를 더하는 경우 Carry가 안 일어남
$a \ \vert \ 2^n$

**뺄셈**
a와 그보다 작은 $2^n$ 을 빼는 경우 Borrow가 안 일어남
$a \ \& \ \sim 2^n$

**보수를 이용한 뺄셈의 덧셈 치환**

A - B 의 경우 

A보다 한 자리 수가 더 높은 수에서 1을 뺀다.
그럼 이제 그것과 B를 빼면 각 자리 수에서 자리 내림이 발생하지 않는다.
그것을 A와 더하고 1을 마지막으로 더해준 결과가 기존 보다 높은 자리 수가 생기면 무시하면 되고 
생기지 않았다면 결과적으로 빼줘야 하는데, 그러기 위해서 다시 보수 계산을 하고 음수를 붙인다.

**곱셈**
	$a \ \ll \ n$
**나눗셈**
- 나머지 
	a를 $2^n$ 로 나눈다면, 그보다 작은 수는 뒤에서 $n$ 개의 비트로 표현됨으로
	$a \ \& \ (2^n - 1)$

- 몫
	$a \ \gg \ n$


### Low Bit 찾기

보수와 & 연산 시 최하위 활성화 비트를 찾을 수 있다.
