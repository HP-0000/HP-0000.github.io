`<=>` 를 사용하면 비교 대상의 순서 범주에 따라 아래 중 하나의 값을 반환한다.
###### 순서가 같으면 데이터도 완벽히 같다.
`std::strong_ordering::less`
`std::strong_ordering::equal`
`std::strong_ordering::greater`
###### 순서가 같아도 데이터는 다를 수 있다.
`std::weak_ordering::less`
`std::weak_ordering::equivalent`
`std::weak_ordering::greater`
##### 비교 자체가 불가능한 상태가 존재한다
`std::partial_ordering::less`
`std::partial_ordering::equivalent`
`std::partial_ordering::greater`
`std::partial_ordering::unordered`

`strong_ordering` ->`weak_ordering` -> `partial_ordering` 순으로 
암시적 변환을 허용한다.

클래스의 경우 다음과 같이 명시하면 
```cpp
auto operator<=>(const MyClass&) const = default;
```

컴파일러는 멤버 변수들 중 가장 약한 범주를 반환 값으로 삼중 비교 연산자를 생성한다.
`User-declared` 동등 비교 연산자가 없다면 추가로 생성한다.
```cpp
auto operator<=>(const Player& rhs) const
bool operator==(const Player& rhs) const
```

삼중 비교 연산자를 `User-declared` 하면 
컴파일러는 동등 비교 연산자를 자동으로 생성하지 않는다.
```cpp
struct Person {
    int age;

    // 내가 손으로 직접 짠 커스텀 <=>
    std::strong_ordering operator<=>(const Person& rhs) const {
        return age <=> rhs.age;
    }
};

Person p1{20}, p2{30};
if (p1 < p2) { ... }
```

컴파일러는 6가지 비교 연산자에 대해 
`==`,`!=`,`<=`,`>=`.`>`,`<`

오버로딩된 연산자를 1순위로 호출하며
삼중 비교 연산자가 구현되있는 경우 비교 연산자들을 
삼중 비교 연산자로 치환해준다.
