### 1. 장의 타입별 라그랑지안 밀도

| 장의 타입 | 대표적인 라그랑지안 형태 | 비고 |
| :--- | :--- | :--- |
| **스칼라장**<br>(Spin 0, 힉스장 등) | $\mathcal{L} = \frac{1}{2}\partial_\mu\phi\partial^\mu\phi - V(\phi)$ | 실수 스칼라장 기준입니다. (표준모형의 힉스장은 게이지 대칭성을 갖는 복소 이중항 스칼라장 형태를 취합니다.) |
| **스피너장**<br>(Spin 1/2, 쿼크/렙톤장 등) | $\mathcal{L} = \bar{\psi}(i\gamma^\mu D_\mu - m)\psi$ | 공변미분 $D_\mu$를 통해 게이지 상호작용이 결합된 디랙(Dirac) 라그랑지안입니다. |
| **벡터장 (질량 없음 / 게이지장)**<br>(Spin 1, 전자기장, 글루온장 등) | $\mathcal{L} = -\frac{1}{4}F_{\mu\nu}F^{\mu\nu}$ | 게이지 불변성을 만족하는 벡터장입니다. 비가환 게이지장(글루온 등)의 경우 $F_{\mu\nu}$ 정의에 자체 상호작용 항이 추가됩니다. |
| **벡터장 (질량 있음 / 프로카장)**<br>(Spin 1, $W/Z$ 보손장 등*) | $\mathcal{L} = -\frac{1}{4}F_{\mu\nu}F^{\mu\nu} + \frac{1}{2}m^2 A_\mu A^\mu$ | 질량을 가진 벡터장(Proca field)의 대표적인 형태로, 게이지 불변성을 깨는 질량항($\frac{1}{2}m^2 A_\mu A^\mu$)이 명시적으로 추가됩니다. |

* **보완 설명**: 표준 모형에서 질량을 가진 벡터 보손($W^\pm, Z^0$)은 본래 게이지 대칭성을 가졌으나 힉스 메커니즘을 통해 자발적 대칭성 깨짐을 겪으며 질량을 얻게 됩니다. 결과적으로 유효 이론 수준에서는 위와 같은 질량을 가진 벡터장(프로카장)의 동역학적 형태를 띠게 됩니다.

|장|들뜬 상태(입자)|
|---|---|
|전자장|전자|
|쿼크장|쿼크|
|전자기장|광자|
|글루온장|글루온|
|W장|(W^\pm)|
|Z장|(Z^0)|
|힉스장|힉스 보손|

---

- **게이지 대칭** = 위치마다 바꿀 수 있는 내부 기준의 대칭
- **게이지장** = 그 대칭을 유지하기 위해 필요한 장
- **힉스 메커니즘** = 게이지 대칭 구조를 가진 채 W/Z가 질량을 얻는 방법

### 2. 표준 모형의 기본장 분류

| 기본장 | 분류 | 장의 타입 | 스핀 | 대응하는 입자 |
| :--- | :--- | :--- | :---: | :--- |
| 업 쿼크장 ($u$) | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 업 쿼크 |
| 다운 쿼크장 ($d$) | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 다운 쿼크 |
| 참 쿼크장 ($c$) | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 참 쿼크 |
| 스트레인지 쿼크장 ($s$) | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 스트레인지 쿼크 |
| 톱 쿼크장 ($t$) | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 톱 쿼크 |
| 바텀 쿼크장 ($b$) | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 바텀 쿼크 |
| 전자장 | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 전자 |
| 전자 중성미자장 | 페르미온장 (물질장) | 스피너장* | $1/2$ | 전자 중성미자 |
| 뮤온장 | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 뮤온 |
| 뮤온 중성미자장 | 페르미온장 (물질장) | 스피너장* | $1/2$ | 뮤온 중성미자 |
| 타우장 | 페르미온장 (물질장) | 디랙 스피너장 | $1/2$ | 타우 |
| 타우 중성미자장 | 페르미온장 (물질장) | 스피너장* | $1/2$ | 타우 중성미자 |
| 전자기장 | 게이지장 | 벡터장 (4-벡터장) | $1$ | 광자 |
| 글루온장 | 게이지장 | 벡터장 (8개의 게이지 성분) | $1$ | 글루온 |
| W장 | 게이지장 | 벡터장 | $1$ | $W^\pm$ 보손 |
| Z장 | 게이지장 | 벡터장 | $1$ | $Z^0$ 보손 |
| 힉스장 | 스칼라장 | 복소 이중항 스칼라장 | $0$ | 힉스 보손 |

> **\* 중성미자 스피너장에 대한 주석:** 
> 표준 모형의 최소 이론에서 중성미자는 질량이 없고 왼손잡이(Left-handed) 성분만 존재하는 바일 스피너장(Weyl spinor field)으로 취급됩니다. 그러나 실제 자연계에서는 중성미자 진동 현상을 통해 질량이 있음이 증명되었기 때문에, 물리적으로 디랙 스피너장(Dirac spinor) 혹은 마요라나 스피너장(Majorana spinor) 중 어느 쪽에 해당하는지에 대해 여전히 연구가 진행 중입니다.
