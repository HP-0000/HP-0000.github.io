수학은 형식 체계를 구성하기 위해, 증명하지 않는 공리를 선택한다.
그리고 그 공리 체계 안에서 논리적으로 도출되는 결과를 만들어 낸다.

과학은 현실 우주를 설명하기 위해, 검증 가능한 가설을 만든다.
그 가설을 바탕으로 수학적 모델을 전개,해석, 실험적 관측을 통한 검증을 거치면서
가설을 수정, 새롭게 대체 하여 보다 더 현실을 잘 설명하는 이론 체계를 지속적으로 발전시킨다.
또한 서로 다른 영역을 설명하는 이론에 대해, 두 영역을 더 잘 설명하는 
일반적인 이론을 찾기 위해 노력한다.

수학에서 공리계는 여러 개 존재 할 수 있으며, 각 이론은 현실을 설명하기에 가장 적절한 수학적 모델을 선택하여 사용한다. 다만 현실은 하나이므로, 같은 상황에 대해 서로 다른 예측을 하는 두 이론이 동시에 옳을 수는 없다. 따라서 충돌이 발생하면 기존 이론을 수정하거나 폐기하거나, 한 이론이 다른 이론의 근사임을 밝히거나, 두 이론을 모두 포함하는 더 근본적인 이론을 새롭게 정립해야 한다.

# 공리계의 한계

###### 거짓말쟁이 역설
`이 문장은 거짓이다.`
우리는 이 문장이 진실인가 거짓인가를 말할 수 없다. 
문장이 참이면 거짓이 되고 거짓이 되는 순간 다시 참이 되며 무한 루프를 돌게 된다.

###### 괴델의 제1 불완전성 정리
모든 기호에 홀수 고유 번호를 부여하고 문장(배열)은 2부터 시작하는 소수의 지수 자리에 
기호 번호를 올려 모두 곱해 괴델 수를 만들어 낸다. 같은 방식으로 괴델 수 자체를 기호 번호로서 소수의 지수 자리에 올려 인코딩 할 수 있으며 모든 문장은 단 하나의 정수로 변환할 수 있다.
괴델수는 항상 짝수 임으로 소인수분해하여 지수 배열로 쪼개며 지수 자리에 짝수가 있으면 
계속 반복하여 디코딩하여 원래 기호를 해석한다.

$g_1$과 $g_2$ 로 부터 $g_3$가 도출된다는 논리학적 기호를   

괴델 수 3개로 이루어진 증명 수 P는 다음과 같다.
$P = 2^{g_1}​×3^{g_2}​×5^{g_3}$

존재하는 문장에 대해서 2부터 올려가며, g_3를 내포하는 증명수P를 찾음으로서 
증명이라는 행위를 완료한다.

G 문장 `괴델 수가 g인 문장은 증명할 수 없다.` 의 괴델수가 g 라고 하자.

g에 대한 증명수 P가 존재한다면 G가 증명되어, 증명수 P가 존재하지 않는다는 결론이
도출된다. 모순이다.

g에 대한 증명수 P가 존재하지 않는다면 G는 참인 문장이 되지만 논리적으로 결과를 도출해 낼 수 없다.

결론적으로, 시스템에 참과 거짓이 존재하더라도 그것을 논리적으로 증명해낼 수 있지 않다.
문장을 증명하기 위해 증명수 P를 올려가며 일일이 대입을 시도하더라도 증명수 P가 애초에 존재하지 않는다면 증명 과정은 논리적으로 결과를 도출하지 못하고 계속 해서 무한 루프를 돌 뿐이다.

###### 튜링의 정지 문제 
프로그램이 다음과 같다.
```
function subroutine(s) 
{
    if exit(s,s) == false
        return true
    else
        loop
}
```
다음은 프로그램과 그 프로그램의 인자를 받아, 
해당 프로그램에서 무한 루프가 생기는지 검증하는 알고리즘이다.
```
exit(subroutine, subroutine)
```
그런데 프로그램 자체가 알고리즘의 결과를 요구하고 있다.
`exit(s,s)` 가 분기문에서 낼 수 있는 결론은 다음과 같다.
1. 알고리즘 자체가 무한 루프에 걸려 답을 내놓지 못한다.
2. 참이거나 거짓이거나. 그러나 이는 대입해보면 모순이 생긴다.

무한 루프를 검증하는 알고리즘은 존재할 수 없다.
